# Git Workflow Standards (Common)

## Core Principles
1. **Branch Strategy**: Keep `main` deployable. Use short-lived feature or fix branches.
2. **Commit Hygiene**: Write clear, descriptive commit messages. One commit should represent one logical change.
3. **Pull Request Scope**: Keep PRs small and reviewable (ideally under 400 lines of changes).
4. **Clean History**: Rebase and squash redundant WIP commits before merging.
